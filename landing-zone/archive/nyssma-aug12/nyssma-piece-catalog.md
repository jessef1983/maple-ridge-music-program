# NYSSMA Piece Catalog

Working catalog of pieces available from currently known NYSSMA library materials.

## Notes

- `NYSSMA level` reflects the level currently attached to your student list when known.
- `Book grade` reflects the publisher's book/series level when available.
- Blank level fields mean the source data does not currently confirm a level.
- This file is intentionally conservative: it includes confirmed contents and confirmed in-use pieces, without guessing missing titles.
